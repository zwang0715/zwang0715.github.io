## About this repository

The site is built with [Jekyll](https://jekyllrb.com/) using the [al-folio](https://github.com/alshedivat/al-folio) theme and hosted on GitHub Pages. It is rebuilt and deployed automatically by GitHub Actions on every push to `main`.
